# Real Brewery
Random brewery and new status effects.

## Features
- New status effects
- Now all recipes in brewing stand are random. They will be remembered on world relaunch and all of them are the same for all players. Like Notch intended (probably)
- You need to drink the potion to learn what it actually it is
- Splash potions - use campfire/lava below of brewing stand
- Lingering potions - use dragon head on top of brewing stand
- cheese...

## Status effects
- **Anonymity**  
    All mobs act neutral. If you hit one of them then it will attack you.
- **Bouncy**  
    Woah! All blocks are bouncy.
- **Cheesefication**  
    Well... You can figure it out...
- **Confusion**  
    What is the name of this item again...?
- **Giant**  
    You're big now.
- **Dwarf**  
    You're small now.
- **Goat Transform**  
    You're goat now. You can dash and scream also.
- **Lava Walker**  
    You can walk on lava, but you NEED to walk on lava to survive. Yeah, like a strider.
- **Magnetism**  
    Items come to you, but you also come to iron blocks.
- **Spiky**  
    Half of damage, that was done to you, will return to attacker.
- **Social Distancing**  
    All mobs will be pushed back from you.
- **Sticky**  
    All blocks act like honey blocks. You can also climb walls now! (you need to crouch for this)
